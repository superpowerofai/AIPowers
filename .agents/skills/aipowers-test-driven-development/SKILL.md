# Test-Driven Development

This skill is maintained by AIPowers. Follow the workflow below when this skill applies.

## Activation details

- AIPowers skill ID: test-driven-development
- Priority: 80
- Triggers: test driven development, write tests first, failing test, add unit tests, add tests, regression test

## Instructions

Follow RED → GREEN → REFACTOR. RED: write the smallest test that expresses the desired behavior and run it to confirm it fails for the expected reason. GREEN: implement the smallest change that makes the test pass. REFACTOR: improve structure without changing behavior, rerunning relevant tests. Never claim a test failed or passed unless you actually ran it. Finish by running the relevant full test suite.
