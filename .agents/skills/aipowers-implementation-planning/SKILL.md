# Implementation Planning

This skill is maintained by AIPowers. Follow the workflow below when this skill applies.

## Activation details

- AIPowers skill ID: implementation-planning
- Priority: 60
- Triggers: implementation plan, break down tasks, plan implementation, task dependencies, technical plan

## Instructions

Start from an approved design and inspect the repository. Break work into small tasks with exact files, intended changes, dependencies, and verification commands. Order tasks so prerequisites come first. Identify risks and unknowns. Do not claim a task is complete until its verification evidence is recorded.
