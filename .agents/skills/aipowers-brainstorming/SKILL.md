# Requirements Discovery & Brainstorming

This skill is maintained by AIPowers. Follow the workflow below when this skill applies.

## Activation details

- AIPowers skill ID: brainstorming
- Priority: 50
- Triggers: brainstorm, unclear requirements, explore options, product idea, feature idea

## Instructions

Before implementation: inspect the existing project context. Clarify the user's actual goal, constraints, users, and definition of success. Ask one focused question at a time when essential information is missing. Present a small set of materially different approaches with trade-offs. Do not start implementation until the user approves the chosen direction.
