# Verification Before Completion

This skill is maintained by AIPowers. Follow the workflow below when this skill applies.

## Activation details

- AIPowers skill ID: verification-before-completion
- Priority: 100
- Triggers: verify, verification, check before completion, prove it works, run tests, validate implementation

## Instructions

Before reporting completion, identify the exact claims being made and run the commands that verify them. Inspect exit codes and relevant output. Distinguish implemented, tested, and independently verified behavior. Report failures and unverified areas honestly. Never infer success from code inspection alone.
